Gestores

Defina quais colaboradores pertencem à equipe de cada gestor (coluna GESTOR DIRETO), e opcionalmente ajuste o GESTOR SUPERIOR quando houver multi-gestor ou quando o DP for responsável.

Como funciona

1) Selecione o gestor (qualquer colaborador pode virar gestor).
2) Marque os subordinados na lista.
3) Clique em Salvar relação.

Isso libera a tela de Solicitações para o gestor solicitar férias (gozo ou venda) para a equipe.

Dicas

• O gestor não aparece na lista de subordinados (evita auto-relacionamento).
• Você pode usar o campo “Buscar colaborador” para filtrar rápido.
• Para cenários de multi-gestor ou DP responsável, use a subaba Gestor Superior.

Gestor Superior (multi-gestor / DP)

Use esta regra quando o colaborador não deve responder apenas ao “GESTOR DIRETO”.

GESTOR: mantém o fluxo padrão (um único gestor direto).
DP: DP pode solicitar férias para ele diretamente.
E-mail: selecione o e-mail de outro gestor quando houver um “gestor acima” ou multi-gestão.

Ordem sugerida

1) Selecione o colaborador.
2) Selecione o Gestor Superior (GESTOR/DP/e-mail).
3) Clique em Salvar.
